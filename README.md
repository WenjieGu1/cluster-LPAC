# Introduction
Cluster-LPAC was developed to overcome the shortages of [L-PAC](https://www.cell.com/cell-reports/fulltext/S2211-1247(24)01332-9). 
Similarly to L-PAC, cluster-LPAC also utilizes the alignment of the best sample to infer the other genetically strongly related sample,
the difference is that we upgrade the criterion of selecting the best sample and we only make an alignment between the samples which 
are similar in relative copy number profile by integrating subclone-aware clustering and excluding low-signal samples.
